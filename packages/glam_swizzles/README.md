# glam_swizzles

The `Vec2Swizzles`, `Vec3Swizzles` and `Vec4Swizzles` traits of the [`glam`](../glam) port of
[glam-rs](https://github.com/bitshifter/glam-rs) 0.33.8 for the Q32.32 vectors `Vec2/3/4` of
[`glam_core`](../glam_core) (28 / 123 / 372 methods, every one a struct construction).

Generated by `tools/codegen/swizzles.py`. Use it through the [`glam`](../glam) facade
(`glam::swizzles::Vec3Swizzles`) or depend on it directly to pay for the float swizzles only.

Compatible with Cairo 2.19.4.
