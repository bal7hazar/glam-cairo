# glam_int_swizzles

The `IVec{2,3,4}Swizzles` and `UVec{2,3,4}Swizzles` traits of the [`glam`](../glam) port of
[glam-rs](https://github.com/bitshifter/glam-rs) 0.33.8 for the integer vectors of
[`glam_core`](../glam_core) (every method is a struct construction).

Generated by `tools/codegen/swizzles.py`. Use it through the [`glam`](../glam) facade
(`glam::swizzles::IVec3Swizzles`) or depend on it directly to pay for the integer swizzles only.
It depends on `glam_core` alone (the integer vector types are in the core).

Compatible with Cairo 2.19.4.
